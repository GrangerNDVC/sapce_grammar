🚀 Générateur de prompts – Space Grammar

Chaque prompt est complet : un seul bloc à copier-coller, rien à assembler. Change le style en haut, tous les prompts se mettent à jour.
Conseils rapides
  • Version minimale pour démarrer vite : les prompts marqués PRIORITÉ (vaisseau niveau 1, 3 ennemis, 1 boss, 1 décor). Le jeu fonctionne déjà sans aucune image (décors de secours dessinés par le code) et prend chaque image dès que tu la déposes dans le bon dossier avec le bon nom de fichier.
  • Génère toute la série dans la même conversation / session de ton outil d'images pour garder une cohérence de style. Pour l'évolution du vaisseau, joins l'image du niveau précédent comme référence si l'outil le permet.
  • Le vaisseau et les ennemis sont demandés dans une seule teinte (cyan pour toi, magenta/violet pour les ennemis) : le jeu change la couleur par rotation de teinte, c'est ce qui permet la recoloration et de varier les ennemis par planète.
  • Musiques : à générer avec Suno ou Udio (gratuit avec limites) en mode instrumental, titre libre. Exporte en MP3, nomme le fichier comme indiqué et dépose-le dans assets/music/. Un fichier manquant = silence, le jeu marche quand même. Les 5 « priorité » suffisent pour commencer.
  • Les prompts sont en anglais (meilleurs résultats). Si tu préfères en français, dis-le-moi et je te les traduis.
